# WhereToTravel

Easily find a travel destination.

## Starting

Create the .env file from the [.env.example](./.env.example).

```env
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_KEY=xxx
REST_COUNTRIES_API_KEY=xxx
```

To start the app on [localhost:3000](http://localhost:3000), you need to run these commands:

```sh
npm install
npm run build
npm run preview
```
